## 1. Research question

Do source-trained physical-state editors lose physical-effect fidelity and counterfactual action-selection utility under appearance changes, beyond native model degradation?

## 2. Frozen commitments already proposed

- [ ] World models remain frozen in the primary study.
- [ ] Initial-condition translation/rotation occurs before the complete observation context.
- [ ] Every physical branch is simulated, not created by changing only the final image.
- [ ] Appearance changes preserve geometry, visibility, camera and physical dynamics.
- [ ] Native counterfactual context is a privileged reference, never a deployable-editor input.
- [ ] No future test observations, repeated editing or physical clamping during autonomous prediction.
- [ ] All siblings stay in a root-family split; root/episode is the uncertainty unit.
- [ ] Main estimand is the native-subtracted, appearance-shift physical-effect error contrast in [EXPERIMENTS.md](EXPERIMENTS.md).
- [ ] Native competence, native equivalence and measurement validity are parallel tests, not post-outcome inclusion filters.
- [ ] Executed candidate-bank regret and endpoint-metric oracle corroborate latent/readout metrics.
- [ ] Test roots remain locked until every selection/tuning decision is frozen.
- [ ] All cells, nulls and numerical failures are reported under prespecified rules.

## 4. Outcome-to-claim rules

| Observation | Permitted conclusion | Not permitted |
| --- | --- | --- |
| Replay or normalization fails | Pipeline is not qualified | Model physics/intervention failure |
| Native prediction fails under nuisance | This checkpoint is not competent on that support | Editor-specific transport defect |
| Independent readout fails on real endpoints | Physical-effect measurement is unqualified | Physical variable absent or ignored |
| Clean editor fails | This intervention family is inadequate cleanly | Appearance specifically breaks a valid interface |
| Immediate readout passes but later effects fail | Temporal inconsistency for this editor/support, with full denominator | Unique physical mechanism identified |
| Positive transport contrast with native competence | Editor-specific excess error on the registered population; appearance damage additionally needs a positive within-editor error change | All world models have the same defect |
| Latent gap without physical decision impact | Measured intervention limitation; utility remains unresolved | Planning is materially worse |
| True-endpoint metric already ranks poorly | Goal/representation scoring can explain part of decision failure | Dynamics/editor caused all regret |
| Augmentation matches a proposed repair | Simple training exposure is sufficient in this setting | Special transport method is necessary |
| Tight equivalence interval around zero | Hypothesized material gap not found at this scope | Universal robustness or causal understanding |
| Wide interval around zero | Inconclusive | Evidence of no effect |

## 7. Honest reporting rules

- A paper's reported result is not our reproduced result.
- A listed checkpoint is not a verified working checkpoint.
- A preliminary hypothesis is not a result or a confirmed literature gap.
- Pretrained-model seeds, editor seeds, planning seeds and environment seeds have different inferential roles.
- Post-hoc analyses are labeled exploratory and require fresh confirmation for new headline claims.
- Optional stopping does not justify repeatedly checking a p-value; use the frozen sample size or a justified sequential design.
- No fabricated numbers, retrospective hypothesis rewriting, hidden failed seeds, or outcome-based deletion.
- No claim of guaranteed acceptance or publication by a particular date.
